## 첫 구현 완료 정의

- 가상 데이터로 입력·조회·수정·저장·재실행 가능
- 원본·추출·AI 제안·사용자 확정값을 구분
- 업무와 주요 변경에서 근거·이력 확인 가능
- 메일 발송 또는 첨부 도착만으로 완료 처리하지 않음
- 불확실한 날짜·담당자·펀드·병합은 확인 대상으로 유지
- 초기 메일·문서 원본 쓰기·삭제 기능 없음
- 실제 검증 결과·미지원 범위·실행 방법을 버전 기록에 명시

## 공통 검증과 자동화 확대 조건

재수집 중복, 사용자 확정값 무단 덮어쓰기, 근거 없는 기한 확정·완료 처리 0건을 검증 사례의 목표로 둔다. 모든 판단에서 근거 또는 부족한 근거를 확인할 수 있어야 한다. 중요 요청 누락과 사용자 수정 시간을 별도로 보고한다.

자동화는 정답 사례 비교 → 검증된 내부 작업 자동 반영 → 지속 운영 순으로 확대한다. 모델의 자신감만으로 실행 범위를 늘리지 않으며, 외부 발송·외부 일정 변경·삭제·자금집행·운용지시 실행은 명시적 승인 대상이다.

관리 시간 30% 감소는 목표이며 실측 결과가 아니다. 기능별 회귀·실패·복구 검증을 완료하고 표본과 한계를 함께 기록한다.

## 후속 우선순위 결정 항목

Teams·Sheets 추가 연결, 보조 모델 비교, 특수 문서 파싱·OCR, 모바일은 핵심 메일·계약 흐름의 검증 결과와 실제 필요를 바탕으로 별도 결정한다. 기존 스키마·예제는 v0.1에서 현행 상태와 일정 구조에 맞춰 보완한다.
