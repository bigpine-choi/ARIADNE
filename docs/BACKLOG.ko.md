## 첫 구현의 완료 정의

- API나 모델 키 없이 가상 데이터와 수동 입력으로 사용할 수 있다.
- 수집 결과와 사용자 확정 상태를 구분한다.
- 날짜만 있는 마감은 Asia/Seoul 날짜로 보존한다.
- 기한 변경과 완료 처리에는 이력이 남는다.
- 메일·Teams·시트 원본에 쓰기 작업을 하지 않는다.
- 실행 방법, 실제 검증 결과와 남은 제한을 README에 기록한다.

## 후속 후보

특수 문서 파싱, 승인된 문서 비교, 첨부 점검, 발송 전 검토, 팀용 서버는 파일럿 이후 별도 작업으로 정의한다. 최초 기획 커밋의 산출물을 실행 가능한 제품으로 표현하지 않는다.
