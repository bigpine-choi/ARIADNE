# ARIADNE

AI가 메일과 문서를 계속 읽고 반복적인 정리·추적·준비를 처리하며, 사용자에게 판단과 승인이 필요한 업무를 모아주는 펀드 운용 업무 시스템입니다. 초기 기획명은 Fund Ops Workbench입니다.

**현재 상태: 개발 계획과 데이터 구조 초안 단계.** 실행 가능한 업무 앱, Outlook 연동, AI 추출·자동 실행은 아직 구현하거나 검증하지 않았습니다. v0.1 구현은 다음 작업입니다.

## 현행 개발 기준

- [개발 계획](docs/DEVELOPMENT_PLAN.ko.md): 목표, 자동화 범위, Godot 검증, v0.1~v0.7 로드맵과 완료조건
- [개발 백로그](docs/BACKLOG.ko.md): 버전별 구현 작업과 검증 항목
- [변경 기록](CHANGELOG.md): 기획 변경과 버전별 기록 원칙

2026-09-30에 합의한 현행 계획은 위 개발 계획과 백로그를 따릅니다. 기존 Electron 중심 6주 계획을 대체하며, **게임 엔진 사용을 검증하고 업무 처리 기능을 화면에서 분리**합니다.

## 제품 목표

- 새 요청, 기한 초과, 회신·승인 대기, 주요 위험을 자동으로 모읍니다.
- 펀드별 일정에 계약문서·조항·계산 규칙을 연결합니다.
- 업무 활동과 변경 이력을 자동으로 축적합니다.
- 근거가 충분하고 검증된 내부 정리 작업부터 자동 반영합니다.
- 사용자 확정값은 보존하고, 충돌하거나 불명확한 항목만 확인 요청으로 보냅니다.

메일 발송이나 첨부 수령만으로 업무를 완료 처리하지 않습니다. 외부 메일 발송, 외부 일정 변경, 원본 삭제, 자금집행·운용지시의 실제 실행에는 명시적 승인이 필요합니다. 초기 버전은 이들의 자료 준비와 검토를 지원합니다.

## 기술 방향

| 구성 | 계획 및 결정 상태 |
| --- | --- |
| 화면 | Godot 우선 검증 후보. 한글 입력·긴 목록·근거 열람·Windows 실행·웹 배포 검증 후 채택 판단 |
| 업무 처리 서비스 | 수집, AI 해석, 규칙 검사, 일정 계산, 작업 실행을 화면과 분리. 구현 언어·버전은 v0.1에서 확정 |
| 개인 파일럿 저장 | SQLite를 우선 검토. 원본 참조·추출 결과·AI 판단·사용자 확정값·감사 이력을 분리 |
| 팀 운영 | 승인된 중앙 서비스와 DB, 사용자별 접근권한. SQLite 파일을 공동 편집하지 않음 |
| 연동 | 과거 메일 파일 가져오기부터 시작하고 Microsoft Graph로 수신·발신 메일 증분 수집 |
| AI | 모델 교체가 가능한 연결 계층. 허용 자료와 검증 결과에 따라 선택하며 모델의 자신감만으로 실행 권한을 부여하지 않음 |

최종 목표는 팀이 공유하는 웹 대시보드입니다. Godot 웹 배포의 적합성이 확인되지 않으면 사용자와 화면 방식을 재검토하며 업무 규칙과 데이터는 재사용합니다.

## 첫 구현 흐름

메일 가져오기 → 업무 생성 → 원문 근거 확인 → 상태 수정 → 재실행 후 보존.

현재 프로젝트의 별도 읽기 전용 참고자료에서 메일 ZIP 5개 안의 `.msg` 523개와 주간업무회의 엑셀 3개를 확인했습니다. 중복 제거 전 파일 수이며, 본문·첨부 분석 또는 추출 정확도를 검증한 결과가 아닙니다. 과거 자료를 오늘의 업무 현황으로 표시하지 않습니다.

원문 메일·계약서·첨부·연락처·계좌·투자자 정보·토큰은 Git 저장소에 올리지 않습니다. 실제 자료와 운영 데이터는 회사가 승인한 저장 위치에서 관리하고, 이 저장소에는 코드·문서·가상 또는 승인된 비식별 예제만 둡니다.
