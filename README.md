# ARIADNE

메일·계약·업무 자료를 읽고 해야 할 일과 근거를 관리하며, 운용지시서·기안문·회신 초안까지 준비하는 펀드 운용 업무 시스템입니다. 초기 기획명은 Fund Ops Workbench입니다.

**현행 방향: 웹 우선 개발 → 업무 서비스 안정화 → Godot 보조 클라이언트 확장.** AI는 근거 있는 추출·제안·설명을 맡고, 금액·일정 계산과 권한·승인·상태 반영은 검증된 코드가 담당합니다.

## 하이웍스 자동화 착수

- 회사 품의서 열람·작성·결재선 설정 화면과 공식 전자결재 API를 분석했습니다.
- 금액·근거를 검증하는 품의서 초안, 보관·재열람·미리보기·HTML/텍스트 복사·다운로드를 구현했습니다.
- 기존 개인 주간보고 생성 시 같은 데이터로 하이웍스용 초안도 함께 보관합니다. 전용 회사 보고 양식은 미확정입니다.
- OpenAI 키는 로컬 화면에서 사용자가 최초 한 번 입력하면 Windows 현재 사용자 DPAPI로 암호화 저장합니다. 재시작·다음 보고 때 자동 재사용하며 교체·삭제도 지원합니다.
- 실제 하이웍스 입력·임시저장·상신, Office Token 연결·콜백·회사 보고 운영은 후속 단계입니다. 기안문 본문은 현재 확정 입력으로 생성하며 AI 문장 생성은 후속입니다.

분석 근거·현재 실행법·API 계약·구체적인 H1~H6 계획은 [하이웍스 자동화 안내](docs/HIWORKS_AUTOMATION.ko.md)를 따릅니다.

## 현재 상태

- 기존 foundation의 Python 업무 모델·저장소·서버를 main에 통합하고 한국어 로컬 웹 화면을 연결했습니다. Godot은 기존 브랜치에 남습니다.
- 공유 폴더 변경 비교·원본 버전 보관·다운로드, Outlook COM 수신/발신 수집, Teams 로컬 메시지 복사 수집기를 구현했습니다.
- 금요일 16시 기준 근거 기반 Excel 보고·본인 메일 발송·중복 방지 및 Windows 예약 등록 도구를 추가했습니다.
- 기존 회귀와 하이웍스·키 저장 검증을 합쳐 로컬 테스트 94개가 통과했습니다. 이전 실제 파일 59개·메일 110건의 제한된 수집 검증은 별도 기록입니다.
- [구현 커밋의 자동 검증](https://github.com/bigpine-choi/ARIADNE/actions/runs/36813656644)은 Windows·Ubuntu, Python 3.12·3.14의 네 조합에서 통과했습니다. 실계정 AI 분석·메일 배달·예약 운영 검증과는 별개입니다.
- OpenAI 키 최초 1회 암호화 등록 기능을 추가했습니다. 실제 키·모델 연결과 Teams 날짜·작성자·전체 범위 검증 전 자동 보고 운영은 비활성입니다. 실제 AI 호출·메일 발송·예약 실행은 미검증입니다.
- 설치·설정·한계: [로컬 수집 및 주간보고 안내](docs/LOCAL_AUTOMATION.ko.md).

## 실행과 확인

Python 3.12 이상을 사용해 저장소 루트에서 실행합니다. 데모는 가상 업무만 만들며 회사 계정이나 OpenAI를 호출하지 않습니다.

```powershell
python -m pip install '.[automation]'
python -m ariadne serve --demo
```

웹 주소는 `http://127.0.0.1:8765/`입니다. 한 사이트의 메뉴에서 **업무 목록 · 업무 자료 · 기안문 · 주간보고 · 연결 설정**을 선택해 이동합니다. 기안문에서는 작성·보관·재열람을, 주간보고에서는 실행 상태와 보관 초안 이동을, 연결 설정에서는 최초 API 키 등록·교체·삭제를 제공합니다. 메뉴 이동은 새 페이지를 열지 않아 작성 중 입력을 유지합니다. 브라우저 뒤로/앞으로 가기와 `/#drafts`, `/#weekly`, `/#settings` 직접 접속도 지원합니다.

업무 입력·수정 API는 있으며 해당 웹 편집 화면은 후속입니다. 현재 다섯 작업 메뉴는 기존 기능을 연결한 것입니다. 계획의 Command Center·Calendar·Funds·Work Queue·Evidence & Audit 전체 대시보드는 아직 완성하지 않았습니다.

실제 폴더를 연결하려면 [로컬 자동화 안내](docs/LOCAL_AUTOMATION.ko.md)에 따라 저장소 밖 설정 파일을 만들고 다음처럼 실행합니다.

```powershell
python -m ariadne.automation_cli --settings C:\LocalConfig\automation.json doctor
python -m ariadne serve --automation-settings C:\LocalConfig\automation.json
```

`doctor`의 키·모델 설정 표시는 존재 여부 검사입니다. 계정 접속·모델 호출 성공을 검증하지 않습니다. 자동 보고 실행·발송 스위치는 기본적으로 꺼져 있습니다. Teams 날짜·전체 수집 범위와 실제 보고 품질 확인 후 예약 운영을 진행합니다.

검증 명령은 `python -m unittest discover -s tests -v`입니다. 운영 DB·원문·설정은 저장소 밖에 보관합니다. 기본 Windows 저장 위치는 `%LOCALAPPDATA%\ARIADNE`이며 `ARIADNE_DATA_DIR`로 바꿀 수 있습니다.

## 업무 목표 범위

- 수신·발신 메일과 첨부에서 요청·담당·기한·선행조건·회신 대기를 추출
- 같은 업무의 진행 이력과 근거 연결, 중복·누락·상충 날짜·금액 탐지
- 정관·약정·변경계약에 근거한 결산·분배·이자·보수·보고·만기 일정
- 확정된 집행정보로 기존 양식의 운용지시서 엑셀, 날인 기안문, 요약 메일 초안 생성
- LP 보고, 주간회의 자료와 인수인계 초안 작성
- 완료 증빙 확인, 사용자 수정 보존, 팀별 접근권한과 감사 이력

메일 발송이나 첨부 수령만으로 완료 처리하지 않습니다. 현재 개인 주간보고 발송 코드는 설정한 본인 주소만 대상으로 하며 `enabled`와 `auto_send`를 명시적으로 켜야 실행됩니다. 임의 수신자 발송·일정 변경·자금집행·운용지시 제출은 향후 별도 승인·권한 기능의 대상입니다. 원본 메일·파일 수정·삭제 기능은 없습니다.

## 연동 역할

| 구성 | 목적 | 도입 범위 |
| --- | --- | --- |
| Outlook COM·Teams 로컬 복사 | 회사 PC의 기존 로그인 세션에서 읽기 | 현재 로컬 구현; Teams 날짜·전체 이력 미확인 |
| MSG·EML·첨부 가져오기 | 계정 연결 없이 과거 업무 흐름 검증 | 첫 실사용 흐름 |
| OpenAI Outlook 커넥터 | 필요할 때 메일·일정을 검색하고 읽는 MCP 방식 연결 | v0.2의 선택적 읽기 실험; OAuth·회사 권한 확보 시 |
| Microsoft Graph | 수신·발신·대상 폴더의 지속적 증분 수집, 장애 복구 | v0.3 |
| Responses API·Structured Outputs | 정해진 구조의 추출·제안, 근거 기반 초안 | 개인 주간보고 코드·가상 검증 구현; 실모델 평가와 업무 추출 확장 미완료 |
| 근거 검색 | 접근 가능한 문서의 버전·조항·페이지·셀을 찾아 제공 | 메일 검색부터 계약 검색으로 확장 |
| ARIADNE MCP | 자체 검색·조회·문서 준비·상태 제안 기능 노출 | 동일한 업무 서비스와 권한 검사 사용 |

Outlook 커넥터의 실제 도구·권한·첨부 접근 범위는 연결 시 확인합니다. 메일 발송, 일정 변경, 첨부 전체 다운로드 또는 누락 없는 상시 동기화를 커넥터의 기본 기능으로 가정하지 않습니다.

## 자료와 검증 범위

2026-10-01 로컬 수집 검증에서는 공유 폴더 Excel 42개·PDF 17개를 보관·재비교하고 원본 바이트를 대조했습니다. 본인 Outlook에서 수신 81건·발신 29건을 수집·재수집했으며 Teams 메시지 본문 복사와 이동을 확인했습니다. 전 사서함·전체 Teams 이력의 완전성이나 첨부 내용 분석 결과는 아닙니다.

이전 계획 점검에서는 메일 ZIP 4개 내 MSG 385개(중복 제거 전 목록)와 주간업무회의 엑셀 3개에 접근했습니다. 엑셀 내용과 메일 파일 목록을 확인했으며 MSG 본문·첨부의 전수 분석 결과는 없습니다. 당시 6월 넷째 주 수신 ZIP은 미전달 상태였습니다. 초기 백서의 ZIP 5개·523개는 더 이전의 목록 집계입니다. 이 수치들을 현재 로컬 수집 건수나 AI 분석 결과와 합산하지 않습니다.

과거 자료에는 분석 기준시각을 표시합니다. 과거의 회신 대기를 오늘의 미처리 업무로 단정하지 않습니다. 원문·첨부·연락처·계좌·투자자 정보·토큰·운영 DB는 Git에 올리지 않고, 코드와 가상 또는 승인된 비식별 예제만 관리합니다.
