# ARIADNE

메일·계약·업무 자료를 읽고 해야 할 일과 근거를 관리하며, 운용지시서·기안문·회신 초안까지 준비하는 펀드 운용 업무 시스템입니다. 초기 기획명은 Fund Ops Workbench입니다.

**현행 방향: 웹 우선 개발 → 업무 서비스 안정화 → Godot 보조 클라이언트 확장.** AI는 근거 있는 추출·제안·설명을 맡고, 금액·일정 계산과 권한·승인·상태 반영은 검증된 코드가 담당합니다.

## 현재 상태

- `main`에는 개발 문서, 초기 스키마·가상 예제와 과거 백서 생성 코드가 있습니다. 이번 변경은 계획 개정이며 제품 출시가 아닙니다.
- 별도 [기초 구현 브랜치](https://github.com/bigpine-choi/ARIADNE/tree/14f47c8ab02a60cb266837041ab0b797f4adb719)에는 Python 업무 모델·저장소·서버, Godot 클라이언트와 테스트 코드가 있습니다. 이번 작업에서 실행하거나 main에 병합하지 않았습니다.
- 첫 구현 작업은 기존 기초 코드를 검토·재사용하고 웹 화면을 연결하는 것입니다. 새 백엔드를 중복 작성하지 않습니다.
- 실제 Outlook 연결, AI 추출 정확도, 계약 일정 및 문서 자동 작성은 이 문서 개정으로 검증된 것이 아닙니다.

## 업무 범위

- 수신·발신 메일과 첨부에서 요청·담당·기한·선행조건·회신 대기를 추출
- 같은 업무의 진행 이력과 근거 연결, 중복·누락·상충 날짜·금액 탐지
- 정관·약정·변경계약에 근거한 결산·분배·이자·보수·보고·만기 일정
- 확정된 집행정보로 기존 양식의 운용지시서 엑셀, 날인 기안문, 요약 메일 초안 생성
- LP 보고, 주간회의 자료와 인수인계 초안 작성
- 완료 증빙 확인, 사용자 수정 보존, 팀별 접근권한과 감사 이력

메일 발송이나 첨부 수령만으로 완료 처리하지 않습니다. 외부 발송·일정 변경·자금집행·운용지시 제출은 개별 실행 승인 대상입니다. 초기 버전에 원본 메일·파일 수정·삭제 기능을 넣지 않습니다.

## 연동 역할

| 구성 | 목적 | 도입 범위 |
| --- | --- | --- |
| MSG·EML·첨부 가져오기 | 계정 연결 없이 과거 업무 흐름 검증 | 첫 실사용 흐름 |
| OpenAI Outlook 커넥터 | 필요할 때 메일·일정을 검색하고 읽는 MCP 방식 연결 | v0.2의 선택적 읽기 실험; OAuth·회사 권한 확보 시 |
| Microsoft Graph | 수신·발신·대상 폴더의 지속적 증분 수집, 장애 복구 | v0.3 |
| Responses API·Structured Outputs | 정해진 구조의 추출·제안, 근거 기반 초안 | v0.2부터 평가 통과 범위 |
| 근거 검색 | 접근 가능한 문서의 버전·조항·페이지·셀을 찾아 제공 | 메일 검색부터 계약 검색으로 확장 |
| ARIADNE MCP | 자체 검색·조회·문서 준비·상태 제안 기능 노출 | 동일한 업무 서비스와 권한 검사 사용 |

Outlook 커넥터의 실제 도구·권한·첨부 접근 범위는 연결 시 확인합니다. 메일 발송, 일정 변경, 첨부 전체 다운로드 또는 누락 없는 상시 동기화를 커넥터의 기본 기능으로 가정하지 않습니다.

## 자료와 검증 범위

이번에 접근 가능한 자료는 메일 ZIP 4개 내 MSG 385개(중복 제거 전 목록)와 주간업무회의 엑셀 3개입니다. 엑셀 내용과 메일 파일 목록을 확인했으며 MSG 본문·첨부의 전수 분석 결과는 없습니다. 6월 넷째 주 수신 ZIP은 이번 환경에 전달되지 않았습니다. 이전 문서의 ZIP 5개·523개는 이전 점검 기록이며 이번 가용 자료 수와 구분합니다.

과거 자료에는 분석 기준시각을 표시합니다. 과거의 회신 대기를 오늘의 미처리 업무로 단정하지 않습니다. 원문·첨부·연락처·계좌·투자자 정보·토큰·운영 DB는 Git에 올리지 않고, 코드와 가상 또는 승인된 비식별 예제만 관리합니다.
