    OUTLOOK / DIRECT CONNECTION

    Outlook 연결

    연결 상태를 확인하고 있습니다.

    1. 최초 연결 설정

    Microsoft 앱 등록의 애플리케이션 ID와 디렉터리 ID를 최초 한 번 저장합니다. 두 ID는 비밀키가 아니며, 클라이언트 시크릿은 입력하지 않습니다. 앱 등록 및 권한 설정은 저장소의 Outlook 연결 안내를 참고해 주세요.

    설정이 변경되었습니다. 저장한 후 로그인해 주세요.

    2. Microsoft 계정 로그인

    로그인 버튼을 누르면 시스템 브라우저가 열립니다. 최초 로그인 이후에는 저장된 로그인 정보를 재사용합니다. 회사 정책상 관리자 승인이 필요할 수 있습니다.

    시스템 브라우저에서 로그인을 완료해 주세요. 로그인 취소는 ARIADNE의 요청을 취소하며, 열린 브라우저 창은 직접 닫아 주세요.

    연결 해제 시 이 앱에 보관한 로그인 정보를 삭제하고 ID 설정은 유지합니다. Microsoft 브라우저 로그인 세션은 별도로 유지될 수 있습니다.

    3. 내 메일 읽기

    로그인한 계정의 선택한 폴더에서 지정 기간의 메일을 읽습니다. 날짜는 한국시간(Asia/Seoul) 기준이며 종료일을 포함합니다. 필요한 메일을 선택해 근거함에 저장할 수 있습니다.

    로그인한 후 메일을 읽을 수 있습니다.

    선택한 메일 본문과 첨부 목록을 이 PC의 업무 DB에 저장합니다. 로그인 정보와 달리 메일 내용은 DB에 암호화되지 않은 형태로 보관됩니다. 첨부파일 자체는 내려받지 않습니다.

    LOCAL OUTLOOK

    이 PC의 Outlook에서 수집

    실행 환경을 확인하고 있습니다.

    클래식 Outlook의 로그인된 사서함에서 읽습니다. 앱 키·시크릿 없이 사용할 수 있습니다. 선택한 폴더의 본문·첨부 목록을 이 PC의 메일 근거함에 저장합니다.

    폴더를 먼저 불러와 주세요. 하위 폴더는 각각 선택하며, 선택하지 않은 폴더는 수집하지 않습니다.

    최대 31일·50건, 최신 메일부터 수집합니다. 본문·주소·첨부 목록은 DB와 백업에 암호화되지 않은 형태로 저장됩니다. 첨부파일 내용은 다운로드하지 않습니다.

    아직 수집하지 않았습니다.
