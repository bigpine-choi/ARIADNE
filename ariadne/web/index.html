자료 연결과 예약 운영

Teams는 평일 낮 12시에 하루 한 번 수집합니다. 키보드·마우스 입력을 보내지 않지만 대화와 스크롤이 잠시 바뀔 수 있습니다. Teams를 사용 중이면 생략하며 오후에 자동 재시도하지 않습니다. PC 종료·잠금·로그인 만료·공유 드라이브 연결 끊김은 수집을 제한합니다. 이 설정 저장과 Windows 예약 작업 등록은 별도입니다.

회사 PC와 오멘 자료 연결

위 폴더 경로를 저장한 뒤 자료 연결 코드를 등록하세요. OpenAI 키·하이웍스 브라우저 코드와는 별도입니다. 두 PC의 Windows 계정에 각각 암호화 저장합니다.

연결 코드는 채팅이나 OneDrive 파일에 저장하지 마세요. OneDrive에는 암호화된 회의 자료만 들어갑니다. 금요일 16시 보관본이 아직 도착하지 않으면 오멘이 보고 생성·발송을 기다립니다.

로그인된 하이웍스 브라우저 연결

하이웍스를 쓰는 브라우저에 ARIADNE 수집 확장을 한 번 연결합니다. 비밀번호·쿠키를 가져오지 않고 문서함과 열람 화면만 읽습니다.

  1. Whale 주소창에 whale://extensions를 열고 개발자 모드를 켭니다.
  2. 압축해제된 확장앱 설치에서 browser-extension 폴더를 선택합니다. 파일을 한 개씩 선택하라는 경고가 나오면 확장앱 압축으로 .whx 파일을 만듭니다. 이 파일은 설치 버튼에서 선택하지 않고, 탐색기에서 확장 관리 페이지의 빈 공간으로 끌어다 놓습니다. .pem은 업데이트 키이므로 설치할 때 선택하지 않습니다.
  3. 위 버튼으로 연결 코드를 복사합니다.
  4. Whale의 확장 메뉴에서 ARIADNE 하이웍스 자료 수집을 선택하고 코드 입력 후 연결 저장을 누릅니다.

코드를 이 채팅에 보내지 마세요. 마지막 응답이확인되어야 연결된 상태입니다. WaterWall 등 회사 보안 프로그램이 설치를 차단하면 보안 담당자에게 승인된 설치 방법을 확인하세요.
